Third-Party Services Dashboard

One search box for all your cloud tools

Claude Code connects to 7 services (Gmail, GitHub, Notion, Google Calendar, Todoist, Linear, ClickUp) through their official MCP servers.

It downloads the data into local JSON files, and a local dashboard searches all of it at once.

Step 1

Log in to ClickUp with the test account

The test workspace holds a startup's "Campus Expansion" plan.

Step 2

Ask Claude Code to download the ClickUp data

The project skill in .claude/skills/ uses ClickUp's official MCP server and saves one JSON file per task in dataExports/clickUp/.

Step 3

Start the dashboard and search

node dashboard/server.js → http://localhost:3000

First ClickUp only, then every service at once.

Summary

Login → download → search

Official MCP servers, test accounts only, data stored locally in dataExports/.

Code, data and docs: github.com/rosenthal-dashboard-test/third-party-services-dashboard
